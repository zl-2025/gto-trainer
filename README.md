# 策略训练与概率计算软件 V1.0

面向策略类卡牌游戏玩家的离线决策训练工具。**零依赖、单文件、双击即用**。

在线体验：**https://gtotrainer.top**

---

## 项目简介

大多数玩家在复盘时依赖模糊记忆——"这手好像打错了""感觉该跟"，但说不清错在哪、错在哪个位置、错了多少次。本工具把定性的策略知识拆成可判定、可统计的练习题，让每一次决策都有明确的判定标准，并把答错的题自动沉淀下来形成长期训练闭环。

整个应用是**一个 144 KB 的 HTML 文件**（3,324 行），不含任何外部依赖、不发任何网络请求、不采集任何用户数据。双击打开即可使用，数据保存在浏览器本地。

---

## 核心功能

| 模块 | 功能说明 |
|---|---|
| **翻前训练** | 覆盖 UTG / HJ / CO / BTN / SB 五个位置的开牌范围，以及 BTN vs UTG、CO vs HJ、BB vs BTN 三种对抗场景。以 13×13 手牌矩阵呈现，点选即判定对错并给出解析。 |
| **翻后训练** | 内置 MDF（最小防守频率）、Alpha、跟注所需胜率三组公式的实时计算器；随机出题练习配合完整推导过程；另含 9 组牌面策略判断，训练持续下注频率的区间直觉。 |
| **听牌赔率** | 常见听牌形态的 Outs 与成牌概率速查，组合听牌（如"同花 + 卡顺"）已做重复计算去重。 |
| **胜率计算** | 基于蒙特卡洛模拟的摊牌胜率与底池权益计算，支持 2–8 人、任意已知手牌与公共牌配置，可指定模拟次数。 |
| **模拟对局** | 2–8 人桌的完整牌局流程，覆盖盲注、翻前、翻牌、转牌、河牌与摊牌，用于把单个决策串联成完整决策链。 |
| **风格测评** | 通过一组情景题评估玩家的打法倾向（松紧度、激进程度），输出风格画像与针对性改进建议。 |
| **策略教学** | 手牌强度阶梯表、位置概念、底池赔率、常见误区等基础知识库，配套术语表。 |
| **学习统计** | 按模块、位置、牌型维度统计答题正确率；错题自动回流至错题本，支持针对性重练。 |

## 技术实现

- **技术栈**：原生 HTML5 + CSS3 + JavaScript（ES5 语法，兼容旧版浏览器）
- **零依赖**：无框架、无构建工具、无 CDN、无第三方库
- **架构**：单文件单页应用（SPA），8 个功能面板通过标签页切换，共享统一状态管理
- **持久化**：localStorage，键名带版本前缀，支持数据重置
- **胜率模拟**：自实现 Fisher–Yates 抽样 + 七张牌牌力评估 + 平局分池逻辑，分批执行避免阻塞主线程
- **范围解析**：将 `55+, A9s+, KTs+` 这类简写字符串解析为手牌集合，再按 1,326 种组合数换算成范围百分比，避免为 169 种起手牌逐个硬编码
- **规模**：3,324 行 / 144 KB / 单文件

## 若干设计取舍

**为什么不用 React / Vue？**
目标场景是本地离线使用、双击即用。引入框架需要构建产物或 CDN，与"单文件、零依赖"的产品定位冲突。用原生 JS + 手写状态管理换取零安装成本，是刻意的取舍。

**为什么数据存 localStorage 而不是云端？**
本工具不收集用户信息，也没有账号体系。训练数据属于个人学习记录，留在本地是隐私最优解。代价是换设备不跟随。

**策略数据是精确解吗？**
不是。范围表整理自公开的标准图表框架，边界手牌做了教学化简化，真实求解器中部分手牌为混合频率。本工具用于**建立范围直觉与训练决策习惯**，不替代专业求解器。
